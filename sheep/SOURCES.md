# Electric Sheep genome sources

Collected 2026-10-16 (all retrievals on that date, UTC times in each `raw/*/_log.tsv`).
Scripts: `~/.cache/fleece-work/scripts/` (`fetch.py` polite fetcher, `build_genomes.py` validate/extract, `analyse.py` census).
Validated genomes: `genomes/<source>/`, one row per `<flame>` in `genomes/index.csv`.
Raw downloads (unmodified): `raw/`. Discarded files and why: `rejects.txt`.

## Sources

See the table at the bottom for counts.

### 1. Live sheep server, generation 248 (current flock): top 1000 by peak rating
- Listing: http://v3d0.sheepserver.net/cgi/best.cgi?menu=best&p=0..14 ("archives sorted by peak rating",
  updated Fri Oct 16 09:02:17 2026): 3779 archived gen-248 sheep with peak ratings -> `raw/ratings_248_live.csv`.
  Also `menu=designer` (designer leaderboard), `cgi/status.cgi`, saved in `raw/live_lists/`.
- Genomes: http://v3d0.sheepserver.net/gen/248/<id>/electricsheep.248.<id>.flam3 for ranks 1-1000
  (peak rating 3587 down to 8) -> `raw/live248/`, `genomes/live-v3d0-gen248/`.
- Note: v2d7c.sheepserver.net and community.sheepserver.net now serve the same gen-248 pages (aliases);
  gen 244/245 files 404 on the live server; gen 247 files are still served.

### 2. Live sheep server, generation 248: stratified `spex` sample
- http://v3d0.sheepserver.net/gen/248/ (directory index of 43,755 ids, saved `raw/live_misc/gen248_index.html`)
- http://v3d0.sheepserver.net/gen/248/<id>/spex for 549 ids: 389 known loops not in the top 1000 (up to 10 per
  1000-id bin), 40 known edges, 120 random ids of unknown status -> `raw/live248_spex/`,
  `genomes/live-v3d0-gen248-spex/gen248-<id>.flam3` (loops), `.edge.flam3` (two keyframes, wrapped in `<flames>`),
  `.job.flam3` (a `<get>` render job: 3 interpolated frames).
  What a spex actually is (checked): for a loop it is byte-identical to `electricsheep.248.<id>.flam3`
  (verified for ids 23, 9045, 43523); for an edge it is two bare `<flame>` keyframes (the two end sheep, time 0
  and time 160 or 320); for 74 of the 549 ids it is a cached render job `<get gen id job><args time bits earlyclip
  isaac_seed transparency format/>` + 3 `<flame>`s at times T-1, T, T+1 (interpolated, named "72.000000" etc.,
  and the `<get id>` is usually a nearby lower id than the directory). 10 ids returned the 5-byte body "None".
- Loop/edge status: archive.org file names `00248=id=first=last.avi` in the 150 `electricsheep-flock-248-*` items
  (https://archive.org/metadata/<item>/files) -> `raw/ia/gen248_videos.csv` (6115 videos, 2151 loops).
- http://v3d0.sheepserver.net/cgi/list?u=<made-up uid>&v=LNX_2.7b12 works (gzipped XML, `raw/live_misc/cgi_list.xml`):
  gen="248" size="800 592", 56 sheep currently live (8 loops, 48 edges), all rating="0".

### 3. Live sheep server, generation 247
- http://v3d0.sheepserver.net/gen/247/<id>/electricsheep.247.<id>.flam3 for: the top 400 gen-247 sheep by peak
  rating in archived v3d0 best.cgi listings (Wayback captures 2017-2022, latest capture per page), plus 137 ids
  whose .flam3 Wayback had captured -> 790 files in `raw/live247/`, `genomes/live-v3d0-gen247/`
  (773 single sheep, 17 two-keyframe edge files).

### 4. Wayback Machine (web.archive.org), sheepserver.net and electricsheep.org
Enumerated with the CDX API, e.g.
`http://web.archive.org/cdx/search/cdx?url=sheepserver.net&matchType=domain&filter=original:.*flam3.*&filter=statuscode:200&collapse=urlkey`
(lists saved as `raw/cdx_*.txt`), fetched as `http://web.archive.org/web/<ts>id_/<original>`.
- Direct genome files: `v2d7c.sheepserver.net/gen/{244,245}/<id>/electricsheep.<gen>.<id>.flam3`,
  `www.electricsheep.org/archive/generation-243/<id>/electricsheep.243.<id>.flam3`,
  and old `spex` files `v2d5.sheepserver.net/gen/169/<id>/spex`, `v2d6b1.../gen/188/...`, `sheepserver.net/v2d6/gen/198/...`
  -> `genomes/wayback-sheepserver-files/`.
- Genome pages `.../cgi/dead.cgi?id=<id>&detail=genome` and `node.cgi?...detail=genome` (genome HTML-escaped
  inside the page; extracted and unescaped): v2d5 (gen 165/169, 2004-05), v2d6b1 (gen 188), v2d7b (gen 243),
  v2d7c captured before 2016 (gen 244) -> `genomes/wayback-sheepserver-pages/` (`wayback_ts` in index.csv).
  gen-247/248-era captures were skipped in favour of the live server.
- Rating listings (best.cgi menu=best/designer/gold) from all eras, plus the latest pre-2016 v2d7c and pre-2022 v3d0
  capture of each best.cgi page found with an uncollapsed CDX query (`cdx_v2d7c_best_2010_2016.txt`,
  `cdx_v3d0_best_2015_2022.txt`) -> `ratings.csv` (gen,id,peak_rating,listing; 11,189 rated ids over gens
  165/188/198/243/244/245/247/248; gen-169 listings are rank-ordered but print no numbers);
  the gen-244 "gold" listing (v2d7c best.cgi?p=0&menu=gold, capture 20120911104802) -> `gold_244.txt` (501 ids).
