# Electric Sheep genomes

**Artwork by Scott Draves and the Electric Sheep** ([electricsheep.org](https://electricsheep.org)).

This directory holds 5,925 real Electric Sheep genomes (flam3 XML), one per file, named `electricsheep.GENERATION.ID.flam3` as the Electric Sheep reuse policy asks. They span generations 165 to 248, the current flock. Those from Scott Draves' own genebank file have no generation and are named `electricsheep.genebank.ID.flam3`. Each `<flame>` carries `fleece_rating`, its peak rating (likes) on the Electric Sheep server where known; 4,945 are rated.

fleece uses this directory as its genebank when `~/.local/share/fleece/genebank/` holds no sheep. Copy the files there to keep a genebank of your own.

## Sources

- the live sheep server, v3d0.sheepserver.net (generations 247 and 248, top-rated and a sample);
- the Wayback Machine (older generations);
- GitHub copies (mikea/iflam, scottdraves/dots, and three small sample flocks).

They were collected on 2026-10-16, at most two requests a second. `SOURCES.md` has the details. Its paths refer to the collection workspace; the raw downloads are not included here.

`ratings.csv` lists peak ratings from the server's "best" pages for 11,189 sheep, including some not in this directory.
